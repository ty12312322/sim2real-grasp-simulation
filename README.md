# Sim2Real Grasping Simulation — 物理参数标定研究

研究机械臂抓取仿真中的接触物理问题与参数标定方法。从合成数据出发，系统性探索 Sim2Real gap 中可量化、可优化的那部分。

## 研究背景

PyBullet 等仿真器在机器人抓取任务中广泛应用，但仿真与真机之间存在系统性 gap。这些 gap 来源于：
- 接触面力学参数（摩擦、刚度、阻尼）在仿真中难以精确建模
- 物体惯性参数（质心偏移）的标定误差
- 执行器与通信系统的隐性延迟与阻尼

本研究构建一个 **支持 10 维参数注入的黑盒仿真器**，并通过黑盒优化（CMA-ES）从真实轨迹反推参数，验证仿真-现实差距的可量化程度。

## 标定的 10 维参数

### 接触面力学（4 维）
| 参数 | 物理含义 |
|------|---------|
| `mu_lat` | 切向摩擦系数（垂直防滑） |
| `mu_spin` | 扭转摩擦系数（防旋转滑脱，仿真默认 0，需单独标定） |
| `k_n` | 法向接触刚度（决定物体形变特性） |
| `c_n` | 法向接触阻尼（决定碰撞动能吸收） |

### 物体惯性参数（4 维）
| 参数 | 物理含义 |
|------|---------|
| `mass` | 物体真实质量 |
| `com_dx, com_dy, com_dz` | 质心偏移（建模默认几何中心，真实分布不均） |

### 执行器与系统（2 维）
| 参数 | 物理含义 |
|------|---------|
| `joint_damp` | 关节黏性阻尼（电机与齿轮阻力） |
| `sys_delay` | 系统通信延迟（10-30ms 量级） |

## 方法

### 仿真器架构
- 基于 PyBullet，加载 Franka Panda 机械臂与标准 cube
- 通过 `changeDynamics()` 注入上述 10 个参数
- 提高求解器迭代次数应对高刚度接触带来的数值爆炸
- 输出多模态时间序列数据（关节状态、力矩、位姿）

### 参数辨识
- 使用 CMA-ES / Optuna 在 10 维参数空间搜索
- 多模态 Loss：关节状态 + 关节力矩 + 物体位姿
- 在合成数据上验证（先设真值，生成轨迹，再让优化器反推）

## 标定结果（合成数据验证）

10 维参数标定误差对比：

```
Parameter      | Ground Truth   | Estimated      | Error %
--------------------------------------------------------------
mass           | 0.1500         | 0.1742         | 16.12%
mu_lat         | 0.8000         | 0.8759         | 9.49%
mu_spin        | 0.0500         | 0.0659         | 31.76%
k_n            | 5000.0000      | 4470.3340      | 10.59%
c_n            | 50.0000        | 10.5562        | 78.89%
com_dx         | 0.0100         | 0.0052         | 48.17%
com_dy         | -0.0050        | -0.0104        | 107.13%
com_dz         | 0.0020         | -0.0109        | 645.27%
joint_damp     | 1.5000         | 1.6295         | 8.63%
sys_delay      | 0.0300         | 0.0265         | 11.74%
```

### 分析

- **6/10 参数误差 < 16%**：`joint_damp`（8.63%）、`mu_lat`（9.49%）、`k_n`（10.59%）、`sys_delay`（11.74%）、`mass`（16.12%）—— pipeline 验证通过
- **3 参数误差大**：`c_n`（78.9%）、`com_dy`（107.1%）、`com_dz`（645.3%）—— 与 Loss 函数对该参数的敏感度不足有关，位姿信号对 mm 级质心偏移和接触阻尼不敏感，需要引入关节力矩信号增强可辨识性

## 文件结构

```
src/utils/          # 工具模块（日志、辅助函数）
scripts/
  01_run_diagnosis.py       # 初始问题诊断
  01_sim_diagram.py         # 仿真流程图可视化
  02_optimize_solver.py     # 求解器优化
  03_system_id_*.py         # 参数辨识的不同尝试（baseline, var2, final）
  04_10var.py               # 10 维参数标定（核心）

```
